# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**DO NOT** file a public GitHub issue. Instead:

1. Email the maintainer directly: **shift+security@someone.section.me**
2. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested fixes (optional)

## Response Timeline

- **Initial Response**: Within 48 hours
- **Assessment**: Within 1 week
- **Fix Released**: As soon as possible based on severity

## Security Best Practices

When using surrealdb-iroh:

- Keep your dependencies updated
- Use TLS certificates for production
- Follow principle of least privilege
- Monitor connection logs for anomalies

## Dependencies

This project relies on iroh and other dependencies. Ensure you also keep those updated to receive security patches.
